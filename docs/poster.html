The Pipeline

story → summary → panel-per-sentence → styled

Two of the four stages are models we fine-tuned ourselves and published to the Hugging Face Hub (core, teal). Summarization gives the image model a coherent, length-controlled script; generation renders each sentence independently. The thesis pipeline (eerie.ipynb) chains them end to end — story → bart-cnn → sd-vist → InstructPix2Pix.

Research Progression

one fine-tuned core, two extensions
Stage 01 · The thesis

Fine-tuned storytelling pipeline

Our own bart-cnn + sd-vist (SD 2.1 / VIST), summarize → generate per sentence → InstructPix2Pix. The fine-tuned models are the contribution.

Core · fine-tuned by us
Stage 02 · Extension

Multi-style, swappable looks

An importable package swaps off-the-shelf SD 1.5 checkpoints (Ghibli · modern-animation · watercolor) to render the same story in three art styles — breadth, not the thesis model.

Extension · off-the-shelf SD 1.5
Stage 03 · Extension

Character consistency

A ComfyUI IPAdapter workflow (SD 1.5, DreamShaper) targets the open problem the core pipeline leaves unsolved: keeping one character on-model across panels. Real before / after.

Extension · IPAdapter demo
